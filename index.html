Audit Methodology & Tools Used

Full Crawl Audit via Semrush

Complete site crawl performed using Semrush Site Audit to surface broken links, redirect chains, orphaned pages, missing tags, slow pages, and duplicate content — producing a prioritised issue list by severity.

Google Search Console Analysis

Impressions vs. clicks gap analysis performed to identify high-ranking pages with low CTR — revealing title tag and meta description optimisation opportunities to improve click-through rates without changing rankings.

Competitor Keyword Gap Analysis

Keyword gap analysis run against top competitors in both fashion and healthcare niches — uncovering untapped ranking opportunities where competitors rank but the client websites had no indexed content or coverage.

GTmetrix & PageSpeed Insights

Performance audits run through GTmetrix and Google PageSpeed Insights for both mobile and desktop — identifying and resolving largest contentful paint, cumulative layout shift, and first input delay issues.

Crawlability & Indexability Check

Robots.txt and sitemap audit confirmed all key pages were crawlable and indexable. No valuable pages were blocked. Index coverage report in GSC reviewed to identify and reinstate any accidentally noindexed pages.

Structured Data Validation

All schema markup tested via Google's Rich Results Test tool. Schema errors resolved and valid structured data confirmed for Product, LocalBusiness, MedicalClinic, and BreadcrumbList types across both sites.

Key Technical Issues Fixed

404 Errors & Redirect Chains

All 404 broken link errors identified and resolved. 301 permanent redirects set up for all changed or restructured URLs — ensuring no link equity was lost during site updates and visitors never hit dead pages.

Duplicate Title Tags & Meta Descriptions

Duplicate and missing title tags and meta descriptions identified across both sites and replaced with unique, keyword-targeted copy — eliminating cannibalisation and improving individual page ranking potential.

Mixed Content (HTTP/HTTPS) Warnings

All HTTP resource references identified and updated to HTTPS — eliminating browser security warnings, ensuring full SSL certificate coverage, and maintaining Google's HTTPS ranking signal across both sites.

Image Compression & Format Upgrade

All oversized images compressed and converted to WebP format where supported — reducing total page weight by 40–60%, dramatically improving mobile load times and Core Web Vitals scores across both websites.

Ongoing SEO Strategy & Maintenance

SEO is not a one-time task. A structured ongoing strategy was defined for both client websites to sustain and improve rankings over time — covering monthly monitoring, content refresh cycles, and backlink development to build cumulative domain authority.

Monthly GSC Review

Google Search Console monitored monthly for new crawl errors, coverage issues, and emerging keyword opportunities

Quarterly Content Refresh

Existing pages reviewed and updated quarterly to maintain topical freshness and improve position for competitive keywords

Backlink Development

Off-page SEO roadmap created — identifying quality link-building opportunities to grow domain authority over time
